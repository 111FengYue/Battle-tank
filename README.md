# 坦克大战 · Battle City

一个使用原生 HTML + CSS + JavaScript（Canvas）编写的经典坦克大战游戏，完全在浏览器中运行，无需任何依赖。

## ✨ 功能特性

- 🎮 经典《坦克大战》玩法：消灭敌方坦克、保护己方基地（鹰旗）
- 🧱 四类地形：砖墙（可摧毁）、钢墙（不可摧毁）、水域（阻挡坦克）、草丛（可隐蔽）
- 🐣 关卡系统：每关 15 个敌人，通关后自动进入下一关
- 💥 粒子爆炸特效、Web Audio 音效
- ⌨️ 键盘操控 + 生命值 / 得分 / 剩余敌军 HUD
- 📱 响应式布局，深色主题

## 🕹️ 操作方式

| 按键 | 功能 |
|------|------|
| `W` `A` `S` `D` 或 方向键 | 移动坦克 |
| `空格` 或 `J` | 射击 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

## 🚀 快速开始

直接用浏览器打开 `index.html` 即可游玩，无需安装任何东西。

## 📁 项目结构

```
.
```

## 🎯 游戏规则

1. 控制你的坦克，击毁本关全部 15 辆敌方坦克即可通关。
2. 保护画面底部的鹰旗基地——它被摧毁则游戏结束。
3. 你共有 3 条命，被敌人击中会损失一条命。
4. 砖墙可被子弹击毁，钢墙无法摧毁，坦克无法穿越水域，草丛可以藏身。

祝你玩得开心！🎉
